### 🔍 发现的坑 / 学到的知识

- **腾讯云 hairpin NAT（内网回环）限制**：服务器内 curl 公网 IP 不通，这是腾讯云经典网络/普通云服务器的特性，公网 IP 绑定在 NAT 网关上，从内网无法回环访问自身公网 IP。解决：用内网 IP 或 localhost 访问。
- **Linux Docker 不支持 host.docker.internal**：Windows/Mac Docker Desktop 自动提供 `host.docker.internal` DNS，但 Linux 需要显式添加 `--add-host host.docker.internal:host-gateway` 参数。
- **Open WebUI 健康检查依赖网络**：容器内设了 HTTP_PROXY 后，健康检查的 curl 请求通过代理发出而非访问本地 localhost，导致死锁。解决：清空代理环境变量 `HTTP_PROXY="" HTTPS_PROXY="" NO_PROXY="*"`。
- **Open WebUI 主分支镜像巨大**：`ghcr.io/open-webui/open-webui:main` 镜像 6.7GB，拉取和启动需要耐心。可考虑使用 `v0.9.2` 等 tag 版本。
- **Flask 自建面板的局限性**：相比 Open WebUI 缺少对话管理、用户认证、历史记录等功能，开发维护成本高。
