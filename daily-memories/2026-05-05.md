### 🔍 发现的坑 / 学到的知识

| 坑 | 解决办法 |
|---|---|
| **腾讯云 hairpin NAT**：服务器内 curl 公网 IP 不通，公网 IP 绑定在 NAT 网关上，内网无法回环 | 用内网 IP 或 localhost 访问服务，外部设备正常 |
| **Linux Docker 无 host.docker.internal**：Windows/Mac 自动提供此 DNS，Linux 没有 | 添加 `--add-host host.docker.internal:host-gateway` |
| **Open WebUI 健康检查卡死**：容器内 HTTP_PROXY 导致自检 curl 走代理连自己，请求死锁 | 设置 `HTTP_PROXY="" HTTPS_PROXY="" NO_PROXY="*"` |
| **Open WebUI 镜像过大**：main tag 镜像 6.7GB，拉取耗时 | 使用特定版本 tag 可减少体积 |
| **config.yaml vs .env 优先级**：gateway 的 QQ_CLIENT_SECRET 被 `.env` 环境变量覆盖，修改 config.yaml 无效 | 必须同步更新 `~/.hermes/.env` 中的 `QQ_CLIENT_SECRET` |
| **secret 写入被截断**：patch 工具写入时某些 secret 被自动截断为 `...` | 使用 `sed` 或 `write_file` 确保完整值写入 |
| **QQ 开放平台重置机制**：第一次查看 AppSecret 仅展示，第二次查看强制重置并生成新值 | 每次重置后立即复制保存，不可二次查看 |
| **Cron job 的 run 操作**：hermes cron job 的 run 是重调度到最近时间点执行，非立即同步 | 理解调度差异，用 run 触发后等待脚本执行 |
